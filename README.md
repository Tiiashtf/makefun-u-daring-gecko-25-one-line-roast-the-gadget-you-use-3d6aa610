A single one-line roast of a gadget used every day, written for the make.fun
competition
[u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610](https://make.fun/bounty/u-daring-gecko-25-one-line-roast-the-gadget-you-use-3d6aa610)
("One-Line Roast: The Gadget You Use Every Day"). A house AI judge compares
the lines two at a time, weighing whether the line roasts a daily gadget,
how funny and fresh it is, how neatly it is worded, and how specific the
gripe is.

## The roast

> My earbuds die mid-sentence every single call, yet survive forty minutes of hold music — even they refuse to listen to my boss.

127 characters, one line. The turn: the earbuds always die at the worst
possible moment — mid-sentence, on a real call — yet happily survive forty
minutes of hold music, as if even they refuse to listen to the boss.

## Run it

```sh
python3 main.py   # writes /output/entry.txt
```

Deterministic: the program always writes the same bytes. It never removes
the output directory itself, only its contents, then writes the single
line. Stdlib only, no network.
